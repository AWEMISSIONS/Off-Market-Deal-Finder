# Off-Market Deal Finder

Rebuild of the visible local-first property research workspace. Organizes manually entered public candidates, investor criteria, source links, evidence, verification notes, buyer call sheets, and a transparent arithmetic worksheet. The worksheet uses only numbers supplied by the user and is not a valuation or recommendation. Data stays in localStorage and can be exported/imported as JSON; there is no live property feed, people search, outbound messaging, or backend.

The matching `AWEMISSIONS/Off-Market-Deal-Finder` repository had no usable source. This implementation reconstructs the visible workflow and does not copy the original property feed or confidential user data.
